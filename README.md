## Comparação EC2 x Lambda

| Aspecto          | EC2                  | Lambda                  |
|------------------|----------------------|-------------------------|
| Gerenciamento    | Alta                 | Quase zero              |
| Escalabilidade   | Manual/Auto Scaling  | Automática              |
| Tempo de execução| Contínuo             | Até 15 minutos          |
| Caso de uso      | Aplicações longas    | Eventos, APIs, triggers |
